เริ่มต้นใช้งานใน 3 ขั้นตอน

01 / INSTALL

ติดตั้ง Firmware

เลือกบอร์ดให้ตรงรุ่น เชื่อมต่อ USB และแฟลชเฟิร์มแวร์ผ่านเบราว์เซอร์

OPEN FLASHER ↗
02 / CONNECT

เชื่อมต่อ Wi-Fi

เปิดเรือ แล้วเชื่อมต่อโทรศัพท์หรือคอมพิวเตอร์เข้ากับเครือข่าย Wi-Fi ของบอร์ด

VIEW GUIDE ↗
03 / CONTROL

ควบคุมเรือ

เปิดหน้า Control ผ่าน IP ของบอร์ด กดเปิดระบบควบคุม แล้วใช้จอยสติ๊กสั่งทิศทาง

LEARN CONTROL ↗

SYSTEM FEATURES / 02

ออกแบบให้เริ่มทำตามได้

01 / USB

แฟลชผ่านเว็บ

ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ แฟลชไฟล์ .bin ผ่าน USB ได้โดยไม่ต้องติดตั้งโปรแกรมแฟลชแยก

02 / WLAN

ควบคุมผ่าน Wi-Fi

บอร์ดสร้างเครือข่าย Wi-Fi ของตัวเอง แล้วเปิดหน้าเว็บควบคุมจากอุปกรณ์ที่เชื่อมต่อ

03 / SAFETY

ระบบหยุดเพื่อความปลอดภัย

เฟิร์มแวร์ ESP32-C5 รุ่นที่ใช้ระบบ failsafe จะสั่งหยุดมอเตอร์เมื่อขาดคำสั่งควบคุมตามเวลาที่กำหนด
