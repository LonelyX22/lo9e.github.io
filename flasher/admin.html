FIRMWARE CONTROL.

Publish firmware builds, manage release history and choose which version appears as LATEST on the public flasher. Firmware files and the version catalog are stored in this GitHub repository.

01 / OWNER AUTHENTICATION

Not connected. Enter an owner token to enable release management.
SECURITY: This page is public, but publishing requires a token belonging to the repository owner. The token is kept only in this tab's memory and is not saved to localStorage or sent anywhere except api.github.com. Use a fine-grained token limited to this repository with Contents: Read and write and Metadata: Read-only. Never share the token.

Create a token in GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Open token settings ↗ Select only LonelyX22/lo9e.github.io. The token is cleared when this page is closed or refreshed.

02 / PUBLISH NEW FIRMWARE

Recommended: upload the complete merged .bin generated for the exact target board. Never mix ESP32 and ESP32-C5 firmware. Maximum upload size: 20 MB.

Verify owner access before publishing.

03 / VERSION CONTROL

Connect as the repository owner to load the release catalog.

04 / PUBLISHED RELEASES

No catalog loaded.
