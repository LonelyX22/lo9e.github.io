จัดการ เฟิร์มแวร์

อัปโหลดเฟิร์มแวร์ จัดการประวัติเวอร์ชัน และกำหนดเวอร์ชันล่าสุดที่จะแสดงบนหน้า Flash สาธารณะ ไฟล์และรายการเวอร์ชันจะถูกจัดเก็บไว้ใน GitHub Repository นี้

01 / ยืนยันสิทธิ์เจ้าของระบบ

ยังไม่ได้เชื่อมต่อ กรุณาใส่ Token ของเจ้าของ Repository เพื่อเปิดใช้งานการจัดการเวอร์ชัน
ความปลอดภัย: หน้านี้เป็นหน้าสาธารณะ แต่การเผยแพร่ต้องใช้ Token ของเจ้าของ Repository เท่านั้น Token จะเก็บไว้ในหน่วยความจำของแท็บนี้ ไม่บันทึกลง localStorage และไม่ส่งไปที่อื่นนอกจาก api.github.com ให้ใช้ Fine-grained Token ที่จำกัดเฉพาะ Repository นี้ โดยกำหนด Contents: Read and write และ Metadata: Read-only ห้ามส่ง Token ให้ผู้อื่น

สร้าง Token ที่ GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens เปิดหน้าสร้าง Token ↗ เลือกเฉพาะ LonelyX22/lo9e.github.io เมื่อปิดหรือรีเฟรชหน้านี้ ระบบจะล้าง Token ออกจากหน่วยความจำ

02 / เผยแพร่เฟิร์มแวร์ใหม่

แนะนำให้อัปโหลดไฟล์ .bin แบบ Merged ที่ Build สำหรับบอร์ดรุ่นนี้โดยเฉพาะ ห้ามใช้เฟิร์มแวร์ ESP32 ปกติปนกับ ESP32-C5 ขนาดไฟล์สูงสุด 20 MB

กรุณาตรวจสอบสิทธิ์เจ้าของระบบก่อนเผยแพร่

03 / จัดการเวอร์ชันล่าสุด

เชื่อมต่อด้วยบัญชีเจ้าของ Repository เพื่อโหลดรายการเวอร์ชัน

04 / เวอร์ชันที่เผยแพร่แล้ว

ยังไม่ได้โหลดรายการเวอร์ชัน

เวอร์ชันเก่ายังคงให้ผู้ใช้เลือกได้ จนกว่าจะเปลี่ยนตัวชี้เวอร์ชันล่าสุด ระบบจะไม่เขียนทับเวอร์ชันเดิม หากต้องการอัปเดตให้เผยแพร่เป็นหมายเลขเวอร์ชันใหม่
