01 / เลือกบอร์ด

เลือกชิป
คลังเฟิร์มแวร์กำลังโหลดรายการ...
เลือกบอร์ดเพื่อดูเวอร์ชันเฟิร์มแวร์ที่เผยแพร่แล้ว

ผู้ดูแลระบบเป็นผู้เพิ่มเวอร์ชันเฟิร์มแวร์ เลือกเวอร์ชันจากรายการนี้ หรือเลือกไฟล์ .bin ของคุณเองด้านล่าง

วางไฟล์ .BIN ที่นี่หรือคลิกเพื่อเลือกไฟล์ · ขนาดไฟล์ขึ้นอยู่กับหน่วยความจำบอร์ด
ยังไม่ได้เลือกเฟิร์มแวร์—

โหมดไฟล์โปรแกรมจะเขียนไฟล์แอปที่ตำแหน่ง 0x10000 หากแพ็กเกจมี Bootloader หรือ Partition ต้องใช้ไฟล์รวมและตำแหน่งที่ถูกต้อง ห้ามนำไฟล์โปรแกรมเดี่ยวไปแฟลชที่ 0x0

ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ และเปิดผ่าน HTTPS เมื่อมีหน้าต่างเลือกพอร์ต ให้เลือกพอร์ตของบอร์ด บางรุ่นอาจต้องกดปุ่ม BOOT ค้างไว้ขณะเชื่อมต่อ

02 / หน้าต่างสถานะ

ยังไม่เชื่อมต่อ
ข้อมูลจากบอร์ด // UART0● รอการเชื่อมต่อ
[ BOAT FLASHER ] กำลังรอเลือกบอร์ด เลือก ESP32 หรือ ESP32-C5 โหลดไฟล์ .bin และเชื่อมต่อบอร์ด

ข้อควรระวัง: ระหว่างแฟลช ห้ามถอดสาย USB หรือปิดหน้านี้ หากแฟลชไม่สำเร็จ ให้เชื่อมต่อใหม่ในโหมด Bootloader แล้วลองอีกครั้ง
