FAQ &
แก้ไขปัญหา

รวมคำถามที่พบบ่อยเกี่ยวกับการแฟลชเฟิร์มแวร์ การเชื่อมต่อ Wi-Fi และการควบคุมเรือ

หน้า Flash Firmware ไม่พบพอร์ต USB ต้องทำอย่างไร?

ใช้ Chrome หรือ Microsoft Edge บนคอมพิวเตอร์ ตรวจสอบว่าสาย USB รองรับการรับส่งข้อมูล ไม่ใช่สายชาร์จอย่างเดียว แล้วถอดเสียบใหม่ หากยังไม่พบ ให้ตรวจไดรเวอร์ USB-to-Serial และลองกดปุ่ม BOOT ขณะเชื่อมต่อบอร์ด

กดเชื่อมต่อแล้วแฟลชไม่สำเร็จ?

ตรวจสอบว่าเลือกชนิดบอร์ดตรงกับอุปกรณ์ ใช้ไฟล์เฟิร์มแวร์ของบอร์ดรุ่นนั้น และอย่าถอดสาย USB ระหว่างเขียนข้อมูล หากยังล้มเหลว ให้เชื่อมต่อใหม่ในโหมด Bootloader แล้วลองอีกครั้ง

ไม่เห็นชื่อ Wi-Fi ของเรือ?

ตรวจสอบไฟเลี้ยงบอร์ดและรอหลังเปิดระบบสักครู่ จากนั้นปิดและเปิด Wi-Fi บนอุปกรณ์อีกครั้ง หากยังไม่พบ ให้รีเซ็ตบอร์ดและตรวจว่าแฟลชเฟิร์มแวร์ที่เปิดใช้งาน Access Point แล้ว

เชื่อมต่อ Wi-Fi ได้ แต่หน้าเว็บเปิดไม่ได้?

ตรวจสอบว่าโทรศัพท์ยังเชื่อมต่อกับ Wi-Fi ของเรืออยู่ แล้วพิมพ์ IP ในแถบที่อยู่โดยตรง เช่น http://192.168.4.1 สำหรับเฟิร์มแวร์ ESP32-C5 ที่ใช้ค่าเริ่มต้นนี้

เปิดหน้าเว็บแล้ว แต่มอเตอร์ไม่หมุน?

ตรวจว่ากด ENABLE หรือ ARM แล้วหรือยัง ตรวจไฟเลี้ยงมอเตอร์ 12V สายสัญญาณระหว่าง ESP32 กับ L298N และการต่อขั้วมอเตอร์ ทดสอบโดยยกใบพัดให้พ้นพื้นและอย่าแตะส่วนที่หมุน

มอเตอร์หยุดเองเมื่อ Wi-Fi หลุด เป็นเพราะอะไร?

เฟิร์มแวร์ ESP32-C5 ที่ใช้ระบบ failsafe จะหยุดมอเตอร์เมื่อไม่ได้รับคำสั่งควบคุมตามเวลาที่กำหนด เป็นระบบป้องกันเมื่อสัญญาณขาด หากต้องการใช้งานต่อ ให้เชื่อมต่อใหม่และเปิดระบบควบคุมอีกครั้ง

มอเตอร์หมุนกลับทิศ ต้องแก้อย่างไร?

ตรวจสอบการต่อสายมอเตอร์ซ้ายและขวา หรือปรับค่าตัวแปร INVERT_LEFT_MOTOR / INVERT_RIGHT_MOTOR ในโค้ดให้ตรงกับทิศทางการติดตั้ง แล้วคอมไพล์และแฟลชใหม่
