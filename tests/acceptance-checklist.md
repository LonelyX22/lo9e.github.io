# Acceptance checklist
- [ ] Camera requires explicit browser permission.
- [ ] Image upload accepts image/* only.
- [ ] Thai/English toggle works and persists locally.
- [ ] History remains local and can be exported/deleted.
- [ ] No image or history upload occurs without consent.
- [ ] Weather is optional and clearly separated from AI results.
- [ ] No prediction is shown when a trained, validated model is absent.
- [ ] Evaluation includes per-class metrics and held-out test set.
- [ ] Test on mobile Safari, Chrome Android and desktop browsers.
